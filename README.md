# 📊 Data Exploration & Cleaning: Credit Default Case Study

## 🎯 About the Project
This repository contains the practical activities and analysis developed during **Chapter 1** of the book *"Data Science Projects with Python"* by Stephen Klosterman. 

The primary focus of this stage is **Data Quality Assurance**. Leveraging my analytical background and investigative mindset from Cybersecurity and Pentesting, I applied a detail-oriented approach to identify inconsistencies, handle missing values, and perform an initial exploration of a real-world dataset containing credit card client financial records.

## 🛠️ Technologies & Tools
* **Language:** Python
* **Libraries:** Pandas, NumPy
* **Development Environment:** Jupyter Notebook integrated with PyCharm

## 🚀 Key Highlights
During this project, I built the foundation for reliable analysis by executing the following steps in the Data Science workflow:
* **Basic Structuring:** Reviewing Python control flow and native data structures (lists, dictionaries, loops).
* **Data Loading:** Importing and reading the case study dataset using Pandas.
* **Data Quality Assurance (QA):** Validating data integrity, such as verifying account IDs to ensure no duplicates are present.
* **Cleaning & Preprocessing:** Identifying and addressing missing or incorrectly masked data.
* **Exploratory Data Analysis (EDA):** Checking consistency against the data dictionary and analyzing structural metrics.

# 📊 Exploração e Limpeza de Dados: Estudo de Caso de Inadimplência

## 🎯 Sobre o Projeto
Este repositório contém as atividades práticas e a análise desenvolvida durante o **Capítulo 1** do livro *"Projetos de Ciência de Dados com Python"* (Stephen Klosterman). 

O foco principal deste projeto é a Garantia da Qualidade dos Dados (Data Quality Assurance). Trazendo minha bagagem analítica e olhar investigativo da área de Cyber Segurança e Pentest, apliquei essa mesma mentalidade minuciosa para encontrar inconsistências, tratar valores ausentes e realizar a exploração inicial de um conjunto de dados real focado no histórico financeiro e inadimplência de clientes de cartão de crédito.

## 🛠️ Tecnologias e Ferramentas
* **Linguagem:** Python
* **Bibliotecas:** Pandas, NumPy
* **Ambiente de Desenvolvimento:** Jupyter Notebook integrado ao PyCharm

## 🚀 O que foi desenvolvido
Durante este projeto, estruturei as bases de uma análise confiável passando pelas seguintes etapas do fluxo de Ciência de Dados:
* **Estruturação Básica:** Revisão de fluxo de controle e estruturas de dados nativas do Python (listas, dicionários, loops).
* **Carregamento de Dados:** Importação e leitura do dataset do estudo de caso utilizando o Pandas.
* **Garantia de Qualidade (QA):** Validação de integridade dos dados, como a verificação de IDs de contas para garantir a ausência de duplicidades prejudiciais à análise.
* **Limpeza e Tratamento:** Identificação e tratamento de dados ausentes (*missing data*) ou mascarados com valores preenchidos de forma incorreta.
* **Exploração Inicial (EDA):** Análise das características financeiras, verificação de coerência com o dicionário de dados e análise de métricas estruturais.
